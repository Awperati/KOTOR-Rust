# Credits

Nothing of these is in this repository or in a build. Each is read at run time from folders on the player's own disk.

- **K1 Underwear Pack v2.0 by LordKinoda** (2008). Body textures for the hero's underwear. The idea and the sheets are the
  author's: "You can use this mod and modify for your personal use as you wish. But if you want to use it for a public mod
  please give me credit for the idea." The game lists the pack as a choice for the player's underwear when its folder is under
  `KOTOR_MODS_ROOT` (default `Mods` beside the projects) and draws its sheets on the body in place of our own paint.
- **High Quality Skyboxes II** by Kexikus. Skybox models and pictures. Its readme: the textures may not be redistributed, the models may with credit. Neither is in this repository or a build.
- **High Resolution Lightsaber Beams** (256x256 blade pictures). Read from the player's folder only.
- **Ultimate Character Overhaul REDUX LITE (TPC)**. Character pictures, apart from the hero's bodies and heads. Read from the player's folder only.
- **Kotor Weapon Model Overhaul** and its **Texture Rework**. Weapon models and pictures. Read from the player's folder only.

The packs above are used only when the settings file has `mod_packs=true` (or `KOTOR_MOD_PACKS=on`), from `KOTOR_MODS_ROOT`. The install's own `Override` folder comes first, then these, then the game's files.
